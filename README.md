COMPUTER HARDWARE: UNDER THE HOOD
Meaning of Computer Hardware
Computer hardware refers to the physical parts of a computer system that can be
seen and touched.
Examples include:
 CPU
 RAM
 Storage
 GPU
 NPU
 Motherboard
 Power Supply Unit (PSU)
 Cooling system
Computer performance depends on how these components work together, not on one
component alone.
1. Central Processing Unit (CPU)
The CPU is the main general-purpose processor of a computer. It executes instructions
and performs calculations.
Important features of a CPU:
 Cores: Independent processing units that execute instructions.
 Clock speed: The rate at which the processor operates, usually measured in
GHz.
 Cache: Very fast memory located close to the processor for frequently used data
and instructions.
 Control and execution: Directs and performs instructions.
Note: A higher GHz or greater number of cores does not automatically mean a faster
CPU. Architecture, cache, workload and power limits also matter.
2. Random Access Memory (RAM)
RAM is the computer&#39;s temporary working memory.

It holds programs and data that are currently being used.
Example: When Chrome, Word and other applications are open, their active data is
held in RAM.
Note: More RAM does not always mean a faster computer. The amount needed
depends on the workload.
3. Storage
Storage keeps data and programs for long-term use.
Two common types are:
HDD
 Uses moving mechanical parts.
 Generally has slower access than an SSD.
SSD
 Has no moving parts.
 Provides faster access and better responsiveness.
 Usually gives faster booting and application loading.
4. Motherboard
The motherboard is the main circuit board that connects the major components of a
computer.
It provides pathways for components to communicate.
Examples of communication interfaces include:
 PCIe
 USB
 SATA
 HDMI/DisplayPort
 Ethernet
 Wi-Fi
A slow communication pathway can create a bottleneck, limiting system performance.
5. Graphics Processing Unit (GPU)

A GPU is a processor specialised in graphics and highly parallel workloads.
Uses include:
 Gaming
 Graphics rendering
 Video processing
 Parallel computation
 AI workloads
Therefore, a GPU is not only for gaming.
6. Neural Processing Unit (NPU)
An NPU is a specialised processor designed to accelerate certain Artificial
Intelligence (AI) workloads.
Difference:
 CPU: General-purpose processing
 GPU: Graphics and parallel processing
 NPU: AI acceleration
Modern computers can distribute different tasks among these processors.
7. Power and Cooling
Power Supply Unit (PSU)
The PSU provides electrical power to the computer&#39;s components.
Cooling System
Computer components produce heat during operation. Cooling systems help control this
heat.
Thermal Throttling
Thermal throttling occurs when a processor becomes too hot and reduces its
performance to control its temperature.
Therefore, a powerful processor can become slower because of excessive heat.
8. Hardware Compatibility
Not every component can be installed in every computer.

Before installing a GPU or other hardware, consider:
 Power requirements
 Cooling
 Physical space
 Connectors
 Motherboard compatibility
Key Point
There is no single most important hardware component.
Computer performance depends on:
CPU + RAM + Storage + GPU + NPU + Motherboard + Power + Cooling + Software
+ Workload
Remember:
Performance = the whole system working together.
The best computer depends on what the computer is being used for.
